# 0.7.41 Plan — Sport Competitions in Career

> **Roadmap position (Pre-FFT `0.7.*` · Core single-ship career):** Builds on the shipped `COMPETE_SLOT` parallel accept/drop flow (`0.5.23`) and turns career competitions into shared timed events (`startsAt`, stake `pool`, barrel hold at the starting planet, rival entries). Ships with classic trajectory-length racing (`SPORT_LENGTH`) first; `0.8.1-plan-max-distance-mode.md` §7 plugs `SPORT_MAXDIST` into the same `galaxy.sport` discipline table, `0.8.2` adds persona appetites (`racer`), and `0.8.3` calibrates final prize pools.

Standalone spec: a fork can rebuild this from this file alone. Source note:
`drafts/rivals-sport-competitions.md` §5.2. Checked against
`archive/0.6.10-plan-map-statistics.md` (`STATS=1` income-per-second table).

---

## Problem & shipped baseline (`0.5.23`)

`0.5.23` already shipped parallel `acceptTask(career, COMPETE_SLOT)` and
`dropTask(career, COMPETE_SLOT)` (`TASK_OFFERED → TASK_ACCEPTED` without
occupying `career.contract`, plus `+3.00` `CAPITAL_REFUND` / clawback when
accepted at Capital). However:

1. Each company's `tasks[COMPETE_SLOT]` is currently rolled independently from
   its private RNG — player and rivals do not see the **same** race!
2. There is no **announcement countdown (`startsAt`)**, no **entry stake** added
   to a shared prize `pool`, no **turret hold** waiting for the starting gun,
   and rivals never enter or race for the pool.

---

## Design

### 1. Shared `galaxy.sport` event mirrored into `COMPETE_SLOT` (`gravity_game.js`)

Follow the exact shared-slot pattern `MEDIC_SLOT` already uses across
`galaxy.actors`:

- `galaxy.sport` holds the active galaxy-wide competition event (or `kind = TASK_NONE`):
  - `serial`, `discipline` (`SPORT_LENGTH` in `0.7.41`; `SPORT_MAXDIST` added in
    `0.8.1`), `planet`, `minLength`, `startsAt`, `deadline`, `baseReward`,
    `pool`, `enteredMask` (bitmask of entered `career.index`), `winner` (`-1`
    until won).
  - Because `GALAXY_SKIP` in `saved_map.js` only skips
    `['actors', 'market', 'period', 'phase']`, `galaxy.sport` packs and unpacks
    automatically in both `SavedMap` run snapshots and `CareerReplay` frames!
- **Announce:** When `galaxy.sport.kind === TASK_NONE` on a board refresh step,
  draw from deterministic galaxy RNG (`galaxy.seed`, `sportSerial`) to announce
  an event at a colonized non-empty planet with:
  - `startsAt = step + Math.round(ANNOUNCE_SEC / DT)` (`ANNOUNCE_SEC = 45`
    world seconds),
  - `deadline = startsAt + Math.round(CAREER.competeSec / DT)`,
  - `pool = baseReward` (`2.00..4.00` baseline, checked against `STATS=1` map
    profit/s so expected race return is ~`1.5×` ordinary flight time).
  - `syncSportSlots(galaxy)` mirrors the active event metadata into every
    company's `career.tasks[COMPETE_SLOT]`, preserving per-company `task.state`
    (`TASK_OFFERED` vs `TASK_ACCEPTED`) and `task.capitalRefund`.

### 2. Enter (`acceptTask`) & drop/expiry (`gravity_game.js`, `career_actions.js`)

- Entering uses the existing `acceptTask(career, COMPETE_SLOT)` (`careerAct('accept', COMPETE_SLOT)`
  — zero new `CareerActions` action types needed!):
  - Allowed while `step < deadline` and `career.ledger.purse + (atCapital ? CAPITAL_REFUND : 0) >= COMPETE_ENTRY`
    (`COMPETE_ENTRY = 0.50`).
  - Deducts `COMPETE_ENTRY` from `career.ledger.purse`, adds `COMPETE_ENTRY` to
    `galaxy.sport.pool`, sets bit `1 << career.index` in `enteredMask`, and sets
    `task.state = TASK_ACCEPTED` (keeping `career.contract` untouched so a
    delivery or medic mission can run in parallel).
  - If accepted at `career.capitalPlanet`, `grantCapitalRefund` still grants the
    `+3.00` Capital entry refund (`task.capitalRefund = 3`), and `dropTask` /
    no-show expiry still claws back `task.capitalRefund` **without** refunding
    the forfeited `0.50` entry stake in `galaxy.sport.pool`.

### 3. Arm before the gun (`gui_aim.js`, `gui_game.js`, `gravity_bot.js`)

- **Crucial origin check:** Only a launch **from `sport.planet`** (`aimBody === sport.planet`)
  while `task.state === TASK_ACCEPTED` and `game.clockSteps < sport.startsAt`
  holds for the starting gun! Launches from *other* planets (`aimBody !== sport.planet`)
  must fire immediately as normal so an entrant who accepted remotely can fly
  to `sport.planet` during the `45 s` countdown.
- When `aimBody === sport.planet`, `task.state === TASK_ACCEPTED`, and
  `game.clockSteps < sport.startsAt`:
  - `queueTurretShot` computes the first EMC barrel alignment at or after
    `Math.max(game.clockSteps, sport.startsAt)` (`slotTurrets[s].fireAt >= sport.startsAt`),
    and the bot's wait/fuel forecast uses the same start floor.
  - Re-aiming, pressing `Esc`, or dropping `COMPETE_SLOT` cancels the held barrel
    immediately, just like any queued turret shot.

### 4. Judging & rival participation (`gravity_game.js`, `gravity_bot.js`)

- **Landing settlement (`settleLanding`):** An entered company (`TASK_ACCEPTED`)
  whose flight **launched at or after `sport.startsAt`** (`flightStartStep >= sport.startsAt`,
  not merely landed after `startsAt`!), originated from `sport.planet`, satisfies
  the discipline threshold (`sim.flightLength >= sport.minLength`), and lands at
  `step <= sport.deadline` wins `galaxy.sport.pool` (`pay(career, sport.pool)`),
  increments `career.competitions`, clears `task.capitalRefund = 0`, and closes
  `galaxy.sport` across all actors (clearing other entrants' `COMPETE_SLOT`
  without refunding their `0.50` stakes, while releasing any `capitalRefund`
  clawback only on voluntary drop/no-show — wait: a rival who genuinely raced or
  lost the race after paying Capital entry does not owe a double penalty if they
  completed a qualifying attempt, or keep `capitalRefund` tied to launching from
  Capital in the race!).
- **Bot entry & racing (`gravity_bot.js`):**
  - Between flights, if `COMPETE_SLOT` is `TASK_OFFERED` and the bot sits at (or
    can reach) `sport.planet` before `deadline` with a candidate clearing
    `sport.minLength` and positive expected value
    `pool * winProb - COMPETE_ENTRY > 0`, the bot calls
    `acceptTask(career, COMPETE_SLOT)` and aims its qualifying trajectory from
    `sport.planet` (holding on the barrel until `startsAt` if early).

## GUI

- **Board row (`gui_book.js`):**
  - Before start: `sport · P# · starts in Ns · ≥N px · pool +M` (`accept −0.50`
    or `entered · gun in Ns`).
  - Live window (`clockSteps >= startsAt`): `sport · P# · live Ns left · ≥N px · pool +M`.
- **Flight HUD (`gui_flight.js`, `gui_hud_text.js`):**
  - Shows entered sport as a secondary work line alongside `career.contract`,
    with a guide arrow to `sport.planet`.
  - While queued at `sport.planet` before `startsAt`, prints
    `armed · race gun in N s` instead of `gun · N s`.
- No canvas banner pill (countdown stays in the HUD/drawer panels).

## Verification

- `experiments/competition_test.js` (wired into `experiments/run_fast.js`):
  1. `galaxy.sport` announces identically across player and rivals with `startsAt`
     and `pool`; two companies entering each pay `0.50` and grow `pool` by `+1.00`.
  2. While entered before `startsAt`, a shot queued on `P_other !== sport.planet`
     fires immediately, whereas a shot queued on `sport.planet` holds until the
     first barrel alignment `>= startsAt`.
  3. A flight launched before `startsAt` cannot claim `pool` even if it lands
     after `startsAt`; first qualifying flight launched `>= startsAt` wins `pool`
     and closes the event for all actors.
  4. `SavedMap` run snapshot and `CareerActions` replay preserve `galaxy.sport`
     and held turret timing deterministically.
  5. `node experiments/run_fast.js` stays green.
