# 0.6.1 plan — the observation device: a visit that reports, and a planet that can be bought quiet

Standalone spec: a fork can rebuild this from this file alone. Source note:
`drafts/politics-quests.md` §3.4. Depends on 0.5.12 (`corruption`, bribe,
arrest) and on the pad model in `orbit_tech.js`.

One reading of the note is assumed and must be confirmed before building:
«possibility to uninstall this device on a planet with high corruption level» is
taken as *the ship's device, removed while standing on that planet* — not a
device that each planet owns.
→ confirmed: `go quiet · P#` uninstalls the ship's `OBS-1` while the ship stands
on the planet (the device stays owned and refits anywhere); the planet itself
keeps nothing.

## problem

The draft's politics has a missing hinge. Today **every** fly-visit pays the
planet's flyby value and decays its rot by `0.2`, whether or not anyone carries a
report back to the Capital, and a bribe pays only because the visit value is still
there. The note asks for a *device* that makes the visit a report: fitted, it pays
and decays rot; pulled off a rotten world, the value stops being cleared, so the
lord's bribe — the same visit value × rot × 4 — is the only way to cash it.

That turns corruption from weather into a choice, and it gives the `1.00` bribe
floor and the `rot 50` arrest line a player-facing reason.

## the model

The observation device is **one ship part**, not a pad gear: the report travels
with the emissary, so it must be a thing the ship carries.

- `OBS-1` joins the part families in `orbit_tech.js` as a new `KIND_OBS` with a
  two-parameter research family `obs (range, mass)` — the hull needs a `MERIT`
  row and a `frontier` row like the others. Stock records:
  `OBS-0` (tier 0, `fitted: false`, mass 0, free) and `OBS-1` (tier 1, mass
  `0.4 t`). Like `hold`/`tank` it refits wherever the ship stands, free back to
  `OBS-0`; like every part it enters `refitMass`.
- `career.ship.obs` is the fitted record (default `OBS_0`), so an existing career
  object needs one field and a `refitShip` that reads it — no new arrays.
- The **visit law** gets one test, in one place. `harvestPlanet` (the entry
  lump) and the rot decay both go through a single predicate
  `reporting(career)` = `career.ship.obs.fitted`, **plus** a per-planet opt-out:

	reporting(career, planet) = career.ship.obs.fitted && !career.market.quiet[planet]

  `market.quiet` is one `Uint8Array(OrbitWorld.PLANETS)` on the shared market
  (like `seized`), so the quiet state is a property of the *planet*, not of the
  company that gave up on it. When the device is pulled off the planet — see the
  "uninstall" rule below — `quiet[planet] = 1`, and no company reports there
  again until the rot is burnt down to `PACIFY_CORRUPTION_MAX` (the medic
  pacification already does that, so a quelled world reports again).

- **What a quiet visit still does.** The entry still stamps `lastVisitStep` and
  `stamp` (the market clock, the planner invalidation and the
  one-bribe-per-visit window are unchanged), writes `visitPay = 0` so the pill and
  `bribeAmount` read the same fact, and **does not** decay rot. The bribe is
  unaffected: it reads `(visitPay + grown) × rot × 4`, so on a quiet world the
  value keeps growing and the bribe keeps rising — the note's "more easy to take
  a bribe". The law stays in one place: `harvestPlanet` gains the `reporting`
  test around its `pay` and its decay, and `estimateProfitLog` gains the same test
  so a predicted quiet landing prices `0` (the 0.5.15 rule: the aim line, the
  book and the rival cannot disagree).
- **Uninstall** is offered on the pad block only while `career.at` is a planet
  with `corruption > QUIET_MIN` (75, the note's number) and the device is
  fitted: `go quiet · <planet>` sets `quiet[planet] = 1` and **unfits** the device
  onto the owned shelf (`career.ship.obs = OBS_0`, mass leaves the ship, the part
  stays owned and can be refitted anywhere — the same rule as every other part's
  free `back`), so a player cannot farm quiet worlds without paying the mass
  twice. Re-fitting `OBS-1` on a quiet planet changes nothing until the rot is
  quelled; the row says so (`quiet · rot 82% · no reports`).

## numbers (starting points, a bench may tune them)

| name | value | meaning |
|---|---|---|
| `OBS_MASS` | `0.4 t` | the price in ship mass, so a light pad pays for it |
| `QUIET_MIN` | `75` | the draft's "high corruption" threshold for uninstall |
| `QUIET_REPORT` | `0` | reports per visit while quiet |

`OBS-1` build cost comes from `buildCostOf('obs', [range, mass])` like every
other part — no price list.

## GUI

- The **flight HUD ship group** gains one row, `report · obs` / `report · none`
  (a `work`-style line, no button): the player must be able to see why a visit
  stopped paying before they hunt for a bug.
- The **pad block** (where the bribe button lives) gains the one action row
  `go quiet · P#` with the confirmation cost in its title, disabled unless the
  conditions above hold, plus the `quiet` line beside `corruption N%`.
- The **help drawer**: the draft asks for a drawer that explains bribe,
  corruption and the device on hover of the bribe button. It is one string
  constant in `gui_tables.js` (beside `COMMON_HELP`) shown by `gui_help.js` on
  that hover, reusing the existing help drawer's preview (no new panel).
- The **profit pill** of a quiet planet keeps its `+0.00` and gains the same
  hatch the seized pill uses, so the map says "this world is quiet" without a
  legend.

## Validation

- `politics_test`: a quiet planet pays `0` on entry, does not decay rot, still
  opens the once-per-visit bribe window, and keeps growing its bribe; its
  neighbours are unaffected; refitting the device on the quiet world changes
  nothing; pacification clears `quiet`.
- `politics_gui_test`: the `go quiet` row appears only above `75 %` and only
  with the device fitted; the `report` row matches `career.ship.obs`; the help
  drawer opens on the bribe hover.
- `career_gravity_bench` A/B (`QUIET=0/1`, seeds 1-12, 1200 s): quiet worlds per
  run, bribes taken, arrests, and purse — a report-free planet must not be free
  money.
- `career_bench`, `career_bot_bench` keep their known failures; `node --check`
  on every touched file, `git diff --check`.

## Scope boundary

No new corruption formula, no change to the arrest roll or the rebellion chance,
no player-set tax (that is `0.6.2`), and nothing about the Capital or A.R.F.,
which never report and never go quiet.
