
## start game option ← `map-fair-start-modes.md`

a start-gift budget in settings (career only), 3 sliders:

- gift for all: 0 (default) … 20 cr
- additional gift for bots: 0 (default) … 20 cr
- additional gift for human players: 0 (default) … 20 cr

the sum is previewed live: 
👀 checkbox to preview example (do not reveal exact what competitors get)
every company, bots included, draws a random 1+
gifts and takes the rest of the budget as cash — at 6 cr that is
e.g. FT-1 + 2 cr., a ship
part (IMP / FT), a random science product (research, not a fitted item — e.g.
IMP-2), radar. 
draws come from the game seed, so a run replays the same gift; a
new seed re-rolls.

→ `0.7.48` (`../../archive/0.7.48-plan-start-gifts.md`): `#giftAll`/`#giftBot`/`#giftHuman` + `👀 example` in the experimental panel; gifted parts are owned, not fitted (the fair-start ship stays unchanged); the example is drawn on a seed no company uses; `ga=`/`gb=`/`gh=` in the address and links.
