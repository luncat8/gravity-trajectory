## 1. Seat search on every roster (`gravity_game.js`)

- **Matching split into helpers:**
  - `seatSites`
  - `seatMatcher`: Kuhn matching inside a pay window
  - `seatPays`
  - `seatAssignmentOf`
  - `assignmentRatio`

  `seatAssignment` runs the same algorithm on top of them, so the ordinary
  walk's numbers did not move.
- **`seatWindowAssignment` / `seatFairAssignment`:** the best weakest/best
  ratio over all pay windows, found with one two-pointer sweep. The
  highest-floor match could keep a needlessly rich seat, so a fair seating of
  the same HQs read as unfair (48/6 seed 1: 0.42 against 0.96).
- **`openingGroupStats(..., windowed, cutoff, order)`:**
  - Seats are traced poorest-first (`openingRiskOrder`).
  - A set is dropped as soon as its traced seats cannot beat the walk's best
    (`openingSeatsCanReach`, `openingCutoff`).
  - Starter exits are memoised per pinned field (`openingExitMemo`).
- **Two walk laws:**
  - `OPENING_LAW_FLOOR` is the measured ordinary walk, unchanged; it still
    runs first on `seats <= 4 && count <= 26`.
  - `OPENING_LAW_WIDE` serves every roster. It prunes sets that leave fewer
    light sites than companies, ranks a heavy/light-balanced pool
    (`openingWidePool`, up to 20 000 sets), reads every set by pay window and
    stops on a trace budget: 2400 body traces below 20 worlds, 8000 from 20 up.
    It is `relaxed`: a cramped world keeps its best (shared, exit-safe) set
    instead of returning null.
  - `planCareerSeats` keeps whichever plan compares better.
- **Removed TEMP instrumentation:** the debug environment switches and the
  walk logs.
- **Tried and dropped** (each was measured on the hard cells, with no gain or a
  loss):
  - pinning every heavy candidate in the proxy;
  - adaptive re-ranking;
  - pair ranking on 6-seat walks;
  - cold ranking everywhere;
  - a `-Infinity` cutoff before the first exit-safe set (it lowered the relaxed
    ratios on 13/4–13/6);
  - a one-swap local search;
  - a 4×2 coarse fan.

## 3. The `+5` ceiling (`planet_gravity.js`)

- I measured the plan's two shapes against the §1 search on the default cell.
  Uniform `+5` failed seeds 1 and 8. A rescaled-hash tail weight (0.5, 0.3)
  failed seeds 8, or 7 and 8. Any redraw moves every planet, so the default
  cell becomes a lottery.
- Shipped instead, as the literal "stretch only the tail":
  - The body draw stays on `−1…3.5` (`BODY_MAX`, same hash and salt).
  - Values from `BIAS_END` (2.8) up are stretched linearly to `MAX = 5` before
    snapping.
