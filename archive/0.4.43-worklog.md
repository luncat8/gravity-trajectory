# 0.4.43 worklog — share 8 %, battery ×2 and engine ×5 research scales

## Implementation

- `BUILD_SHARE` 0.10 → 0.08: EMC-1 3.04, EMC-2 7.83 (still above the 7.74
  starter floor, checked on seed 1 and on all 302 starter-blocked planets).
- Research scales: battery `METRIC_SCALE` ×2 (1 RU = 2.5 kWh, 0.0002 leak),
  engine `METRIC_SCALE` ×5 (1 RU = 2 kN, 0.2 t). Both are the research scale,
  so the science-tab fee moves with the build price (see below). The GUI metric
  line derives from the scale, so it reads the new units itself.
- Pins that encode the old units moved: frontier and overshoot values in
  `career_bench`, the engine research purses (2000 instead of 200), `dom_smoke`
  price strings, the metric line and the 1.50 → 7.50 RU mass surcharge, and
  the engine purse in the live-range check (1000 instead of 100).
- `build_cost_probe.js` log regenerated for the new values.

Against the 0.08 share without the scale change, batteries rise 1.8–2.0× and
engines 4.5–4.8×. The engine multiple sits under 5× because the base fee does
not scale; a 5× factor on the build would need a per-family base change.

## Side effect on research fees (not requested, reported)

Inside the known hull the fee is the base only, so it does not change. Outside
the hull it follows the scale:

| target | 0.4.42 (before) | 0.4.43 (after) |
|---|---|---|
| engine 26 kN / 0.5 t | 23.56 | 106.98 |
| engine 60 kN / 0.5 t | 66.62 | 319.75 |
| engine 26 kN / 1.8 t (inside) | 1.28 | 1.28 |
| battery 20 kWh / 0.0006 | 11.36 | 21.73 |
| battery 10 kWh / 0.0002 | 9.34 | 17.18 |

An off-range engine now costs far more than the 6.00 starter purse, so the
first new engine waits for income. If that is too steep, lower the engine
research scale and accept a lower build multiple, or raise the purse.
