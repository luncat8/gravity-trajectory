## what the matrix measured

`MATRIX=1 node experiments/career_start_fairness.js` (`seeds 1-12`, `ratio >= 0.55`):

- **Only 7/25 cells ship 12/12 fair** (`13/2`, `20/2..4`, `26/2..4`).
- **Every `COUNT >= 20` cell (`20, 26, 48` × `2..6`, 15/15 cells, 180/180 seeds)
  has an exitable, `>= 0.55` fair HQ set** (`altFair 12/12` across the board).
  The current planner ships `1/12` (`20/5`), `2/12` (`20/6`), `3/12` (`26/5`),
  `3/12` (`26/6`), and `10, 10, 9, 8, 3 / 12` (`48/2..6`), taking up to
  `6705 ms` mean / `8000 ms` max on `48/6`.
- **Two separate bugs inside `gravity_game.js` cause all `COUNT >= 20` failures
  and the `13/5` misses:**
  1. `seatAssignment` (including `seatBestRatio`, which passes `fixedFloor=true`
     instead of walking lower-floor pay windows) maximizes `floor` first and
     can pick a lopsided site for one rich seat. On the game's *own* already-pinned
     HQs, `bestRatioAssignment` alone lifts `sameHQ oracle fair` to `12/12` on
     `48/2..5`, `9/12` on `48/6`, `3/12` (`20/5`), `4/12` (`20/6`), `6/12` (`26/5`),
     and `4/12` (`26/6`).
  2. `planCareerSeats` checks `seatsWanted <= 4 && count <= 26`: every `S >= 5`
     or `C=48` cell bypasses `planHomeSet` and calls `pickFairHq` once per seat.
     `pickFairHq` prefers `g <= 1.0` (`shallowOnly=1`) — spending light buildable
     worlds as HQs instead of heavy planets — never checks distinctness or pay
     ratio, and re-runs `careerOpenings` per seat (up to `8.0 s` on `48/6`).
- **Genuine constraints occur only at `COUNT <= 13`:**
  - `13/5`: game ships `2/12` buildable, `0/12` fair; exhaustive check over
    all HQ sets finds **`9/12` exitable and `6/12` fair** (`seed 10` has
    `lightBefore=4 < 5`; `seeds 1, 8` yield 0 buildable distinct sets).
  - `13/6`: game ships `0/12`; exhaustive check finds **`5/12` exitable and
    `0/12` fair** (`6 + 6 = 12` non-Capital planets leave zero spare sites).
  - `13/4`: game ships `9/12` fair (`seeds 8, 10` unbuildable in all 495 sets;
    `seed 1` has an unfair `0.19` exitable set missed by `OPENING_EXACT_MISS=48`
    / `OPENING_EXACT_SETS=400`, `altExit 10/12`).
  - `13/3`: `11/12` fair (`seed 10` has `lightBefore=4` and 0 buildable sets across
    all 220 triples).
  - `8/2`: `10/12` fair exhaustively (`seed 8` has negative A.R.F. payouts
    `-3.00 / -1.94`, `ratio 0.00` despite `11/12` exitable; `seed 10` has
    `lightBefore=2` and 0 buildable distinct sets).
  - `8/3`: `4/12` fair, `7/12` exitable exhaustively (5 seeds unbuildable in all
    sets; 3 exitable seeds cap at `0.33–0.42`).
  - `8/4..6`: `0/12` buildable in all HQ sets (`7` non-Capital planets `< 2 * SEATS`).
