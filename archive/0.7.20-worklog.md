# 0.7.20 — Radio entry point and affordable evacuation

- Made the always-visible H control explicitly a radio entry point (`☏ H`) with an accessible label that says it opens the assistant. A stranded ship now raises H's call badge even before the player tries to launch, including when it has been lost in space. The button still opens the helper dialog on demand.
- Evacuation is now available when the purse is below the full fare: it spends up to the cash on hand and uses the extra travel time instead of ending the run as broke. At ×1, duration maps linearly from 12 real seconds at full fare to 240 seconds at zero fare; the active playback pace scales the actual wall-clock duration. The HUD shows the quoted payment, estimated real seconds, and progress.
- Added live evacuation quotes to H, launch status and the stranded-ship shop hint. Career accounting now records the actual evacuation spend, not a full fee per rescue.
- Validation: COMMS call/facts/topics/page tests, career statistics, wear, launch-reason tests, and the full DOM smoke test pass. `career_bench.js` still has the same three unrelated failures as the base checkout (delivery offer fixture, cargo cap fixture, communist completion fixture); its evacuation case passes with full, partial and zero fares. `career_bot_bench.js` was started during a temporary bot-policy experiment and stopped; bot code was reverted, so that run does not validate the final tree. `bribe_score_test.js` passes.

Next: consider adding an explicit low-purse evacuation scenario to the player onboarding/tutorial, now that the rescue action can be used without full fare.
