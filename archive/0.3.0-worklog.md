## 0.3.0 step 1 — 2026-10-21 — playback speed & planet photo deck

Two of the requested features are cheap and self-contained; the other three
(a route mode without a length limit, a money economy, a bot) each need a
measured design, so they ship as standalone plans with the measurements that
motivate their constants.

### playback speed

- One multiplier now scales the wall-clock slice fed to the fixed-step physics:
  `stepGame` accumulates `dt · playScale · replayMult` and feeds 1/60 s slices to
  `advanceGame`, so a flight can be watched at ×0.25…×8 (lab flights use the same
  scale directly). Physics steps, aim grid and the recorded shot list do not
  change — a replay is still a pure function of its shots, which `game_bench`
  keeps proving (144 Hz, jitter, ×16 and skip all identical).
- Replay multipliers are now `0.25 0.5 1 4 16` instead of `1 4 16` (the sketch
  asked for *slower* as well); the live and replay multipliers compose and are
  clamped at ×32 so a 120 s flight cannot stall a frame.
- New `playback` group in the panel: `− slower` / `×1` / `+ faster`, with the
  world-rate slider still locked by the fixed-rate rule (a link's rate must not
  change, or the replay would diverge).

### photo deck

- `photo_deck.js` (new, no DOM at load beyond the markup it looks up): shows a
  postcard bottom-left when a planet system is entered for the first time in the
  run and when the cargo lands. Type comes from the seeded world
  (`rock, terran, super, dwarf, mini, gas, ice`), so each seed shows the pictures
  that match its worlds; a gas giant landing is the air-platform card.
- Art is optional: `photos/space/<type>[-n].jpg|png` and
  `photos/landed/<type>[-n].jpg|png`; candidate order is variant → plain → jpg →
  png, each miss falling through on the image error event. A missing file shows
  a CSS postcard of the same type (`::before` disc per type, ring for the ice
  giant, horizon + ground for `landed`), so the feature is complete with zero
  assets and stays useful when only some pictures exist. A URL that already
  loaded is remembered so reopens do not refetch.
- Placement: fixed bottom-left above the trade footer, width `min(340px, …)`,
  aspect kept by the `img`'s own `auto` sizing, capped at 34 vh so the card
  never eats the canvas. Below 960 × 640 it becomes the allowed 256 px overlay
  at z-index 9; the class is re-evaluated on resize.
- Once per planet per run (two bitsets, reset by `clear`/`abort`/`restart`);
  auto-hides after 9 s, `×` closes it.
- Two demo pictures generated from the prompt pack (`photos/space/terran.jpg`,
  `photos/landed/gas.jpg`) so the card has real art out of the box.

### art prompt pack

`photos/prompts.md` — fourteen captions (7 types × space/landed) written as
finished-picture descriptions, which is what both requested models want: Krea 2
documents natural-language, long, detailed prose (its text encoder is a
language model; it has no CFG, so no "no X" phrasing), and MOSS-Image documents
caption-style prompts with Euler · ≥50 steps · CFG 3.0 · shift 5.0, sides
divisible by 16, and a fixed negative tag set. Settings, file names, the
optional `-2/-3` variants and an asset checklist are in `photos/README.md`.
