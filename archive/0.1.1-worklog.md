# 0.1.1 — longer default trajectory with adjustable horizon

Task: make the calculated trajectory 3x longer by default and add a slider for it.

## changes

- `gravity_sim.js`: default horizon 20 s -> 60 s (`HORIZON`, `MAX_STEPS` 2450 -> 7350, `PATH_MAX` 2500 -> 7500). Horizon is now per-instance (`this.horizon`, default 60) and `predict()` stops at `this.horizon`; max steps scale with the chosen horizon. `GravitySim.HORIZON` exports the new default.
- `index.html`: added "trajectory horizon" slider (`#horizon`, 5…60 s, step 5, default 60) in the cargo panel.
- `gravity_gui.js`: wired `#horizon` to `gravity.horizon`, updating its label/tag and invalidating the prediction on input.

## validation

- `node --check` all classic scripts: pass.
- `node experiments/gravity_bench.js`: 5616 predictions, avg 0.129 ms, worst 2.916 ms (within 10 ms), 0 budget truncations; parity 216 shots, max deviation 0.000068 px; repel sweep finite.
- `node experiments/dom_smoke.js`: SMOKE OK.
