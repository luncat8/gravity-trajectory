# 0.4.35 worklog — trajectory sonification

## Review of the previous state

0.4.34's science-merit work is unrelated to audio and was left untouched. The
existing sound player already handled late sample readiness, media errors,
restart fade races, mute and backgrounding; those paths are preserved rather than
rewritten. The new work adds a third backend beside the existing sample player
and fixed procedural fallback.

## Implementation

- `gravity_trajectory_sound.js`: separate sample-free Web Audio generator with
  deterministic `get_tone_pentatonic(planet_id)` and `get_instrument(planet_id)`.
  Persistent chord/flight voices, a small pluck pool, fixed event buffers and a
  limiter keep the frame path allocation-free. Context creation/resume remains
  gesture-gated; backgrounding suspends the graph.
- Aim telemetry reads the existing prediction and career economics: net profit,
  path length, destination, EMC tier/speed and departure viability. Two mappings:
  outcome chord + length ticks + EMC beacon, or a compressed visit-log
  fly-through with planet notes and screen-side pan. Partial route traces do not
  emit a final destination phrase.
- Flight telemetry uses the nearest active planet. Pentatonic proximity keeps a
  stable planet note and maps distance to loudness; instrument range maps the
  same planet to a stable timbre, with farther = higher pitch and lower volume.
  Both use equal-power left/right pan. Burn previews duck the flight cue.
- `gravity_sound.js`: `createController` switches between trajectory, selected
  samples and classic fallback while preserving mute, volume, active state,
  loop phase and flight state. A mid-flight switch restarts only the flight cue,
  not the ignition or simulation. `GravitySound.create` keeps its old behavior.
- GUI/settings: collapsible sound group with generator, aim mapping, flight
  mapping and volume selectors; local persistence with validated defaults.
  Route plans remain audible after release in the trajectory generator; classic
  engines keep the old silent route-armed behavior. Replays and rivals stay silent.
- Docs: README and sounds/README describe the three generators and mappings.

A browser check caught a real preference bug: an absent volume key was coerced
from `null` to `0`, silencing the fresh default. The loader now distinguishes an
absent key from an explicit zero.
