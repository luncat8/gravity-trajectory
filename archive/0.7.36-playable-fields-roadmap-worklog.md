## 1. Review of `0.7.35` (Map Helper & Saved-Map Picker)

Reviewed `planet_gravity.js`, `map_gen.js`, `map-generator-helper.htm`,
`saved_map.js`, and `gui_maps.js`:

1. **`MapGen.savedMapFields` ignored `record.gravity` on `field` records**:
   reconstructed values via `originalDraw(record.seed, universe)` instead of
   reading `record.gravity`. Fixed to read and snap `record.gravity` whenever
   present.
2. **`MapGen.fieldRecord` / `readFields` stripped proven `seats` and `targetPay`**:
   loading or saving a second field in `map-generator-helper.htm` wiped seats
   proven by `make_saved_maps.js` off untouched fields. Fixed `fieldRecord` so
   untouched fields preserve `seats`, `targetPay`, career start settings, and
   `stats`, while editing or re-rolling a field's `values` drops stale `seats`
   until re-planned.
3. **`loadField` in `map-generator-helper.htm` mutated the old roster and
   clamped range**: `applyRange()` ran before `planets` was replaced and shrunk
   `gravMin..gravMax` below `-1..3.5`. Fixed to preserve `PlanetGravity.MIN..MAX`
   (widening if needed) and replace `planets` before refreshing; also wired
   `pointercancel` alongside `pointerup` on `#mapSvg`.

## 2. Implementation of `0.7.35` Playable Designed Fields (`archive/0.7.35-plan-playable-fields.md`)

- **`planet_gravity.js` & `gravity_game.js`**:
  - Added seed-scoped `PlanetGravity.arm(values, seed)`, `disarm()`, `armed()`,
    and 32-bit FNV-1a `fieldTag(values)`. `gravity(seed, planet)` returns the
    snapped armed value only for the matching `seed` and `0 <= planet < length`,
    leaving any other seed or out-of-range planet on the seeded hash draw.
  - Appended `:<fieldTag>` to `seatPlanKey` when an armed field matches
    `world.seed`, preventing `seatPlanCache` collisions between a seed's rolled
    field and a designed field on the same seed.
- **`saved_map.js`, `index.html`, `gui_maps.js`, `gui_world.js`, `gui_share.js`, `gui_game.js`, `gravity_gui.js`**:
  - Loaded `map_fields.js` in `index.html` right after `saved_maps.js`.
  - Added `GravityMaps.applyField(record)`, `fieldTag` verification in
    `applySeats`, and automatic `gravity` capture in `startRecord` / `runRecord`
    when a field is armed.
  - Listed `MAP_FIELDS` (`field:0..M-1`, `· field`) alongside `SAVED_MAPS` in
    `#mapPick`, `load map`, and `?map=<name|field:i|index>`.
  - Unseated `field` records pre-plan their opening via `planFieldOpening`
    (`prepareCareerStarts` + `openingGroupStats` fairness gate) before touching
    the live session — refusing trapped/all-heavy fields with `no fair opening
    in this field` and caching fair plans so `startGame` needs no second search.
  - Retained `map=<name>` in `syncSeedUrl` while a registry field is armed, and
    disarmed cleanly on `?seed=`, `new seed`, seed `#game=1` links, and seed
    switches.
- **Career replays (`career_replay.js`, `gui_career_replay.js`)**:
  - Carried and range-validated optional `gravity` in both compact
    `CareerActions` (`GRAVITY_ACTIONS:...`) and full `CareerReplay` movies,
    arming the designed field automatically when replayed on a seed-only page.
- **`experiments/make_saved_maps.js`**:
  - Added `FIELDS=1` / `FIELDS=<path>` mode to prove and write `seats` +
    `targetPay` into `map_fields.js` (refusing unfair fields with exit code `1`)
    and extended `--check` to verify seated field records.
