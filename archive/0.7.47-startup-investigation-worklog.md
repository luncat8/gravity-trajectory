# 0.7.47 startup investigation — 2026-11-25

## Findings and changes

- A search that exceeded the synchronous budget left the game in planning even
  after finding an accepted opening. There was no career yet, so the shop and
  helper controls looked broken. The test harness drained planning, masking the
  real frame-loop behavior. Accepted plans now start automatically, and the
  asynchronous handoff refreshes the UI and creates the recording after seating.
- Completed, unaccepted tiers now offer their snapshot while the next tier runs.
  An overcrowded composition starts its completed fallback; after the last tier,
  H offers the completed plan or a no-plan fallback and saved maps. Only
  completed tiers can be committed. A no-plan fallback skips repeating the same
  synchronous seat search.
- H's search call used a key containing changing search data. Progress could
  dismiss it while the game clock was frozen, preventing a replacement call.
  A previous ended career also suppressed or replaced the search report. Search
  calls now stay stable, reset on a new planning run, and take precedence over
  stale career state. The report distinguishes no candidate from a live best,
  explains unmet criteria, shows estimated first-landing pay and the weakest
  share, and labels pass progress as approximate. The status line names planning.
- The search is cooperative work on the main thread, not a Web Worker. Its 8 ms
  frame budget is a target: an atomic search unit can exceed it. The first slice
  still has the requested 2 s synchronous budget.

## Validation

- `fair_start_gui_test`: passed, including real frame-driven 14-planet / three-
  company new-seed planning, restart seat parity, stale ended-career radio,
  live call stability, asynchronous acceptance and UI/recording, continued
  tiers, early play, exhausted/no-plan fallback, cramped-roster fallback and
  loading a save. The acceptance and edge cases use controlled search results.
- `seat_search_test`, `comms_facts_test`, `comms_topics_test`,
  `comms_call_test`, `comms_page_test`, `career_pause_test`: passed.
- Syntax checks and `git diff --check`: passed. Full smoke and seed sweeps were
  deferred; no HTML, script order or composer wiring changed. An attempted
  `comms_copy_test.js` command failed because that file does not exist; the
  four named comms tests above were run instead.
