## 2. Implementation

- `gui_lite.js` (new area, loads after `gui_maps.js`): `liteMode` from `?lite=`
  or `localStorage['gravity.lite']`; the `#liteMode` box in the view bar stores
  the choice and drops the address override; `liteRecords`/`liteSeeds` (start
  records fitting universe, seats, scales, no designed field); `liteBootSeed`,
  `newRunSeed` (cycle saved seeds, Shift = random), `liteArmOpening` (called by
  `startCareerRun` before `applySeats`), `syncStillBackdrop`, `applyLite`.
- `orbit_view.js`: no fast-forward on load; `reset(seed, deferHistory)` +
  `settle()`; still mode (`setStill`) paints `paintStill()` only when
  `stillDirty` or a planet's state/port changed, never steps the idle trade
  world, skips moons/ships/hover; shared `beginPaint()`; `IDLE_DASH` replaces a
  per-frame `[3, 7]` allocation; counters `paints()`, `fastForwards()`.
- `gravity_gui.js` boot: `applyLite()`, `scene.reset(startupSeed(), true)`, and
  `if (scene.settle()) attachWorld()` when no run started. Sound controller
  created with `soundEnabled && !liteMode`; `new seed` uses `newRunSeed(shift)`;
  `GravityScene.liteMode()`.
- `gui_world.js`: `startupSeed` → `liteBootSeed` in lite; `syncSeedUrl` writes
  `lite=` back only when the address carried it.
- `gui_view.js` `applyMode` → `syncStillBackdrop()`; `gui_frame.js`
  `refreshSoundToggle` shows lite's hold (off, disabled, tooltip).
- `photo_deck.js`: `setEnabled` / `enabled`; `show`, `showCareer`, `toast`
  return early while off.
- `saved_maps.js`: regenerated with new `CONFIGS` entries for 13 worlds: 2 seats
  (seeds 6, 7, 8) and 4 seats (seeds 6, 7, picked from alternate `b987883`) —
  pure append, earlier records are byte-identical. 1-seat (`off`) searches take
  ~0.3 s, so no record for them. `newRunSeed` also falls back to `randomSeed()`
  when a single-record roster is already on its saved seed so `new seed` never
  repeats the live world, and `stillStale` checks `portSpec` alongside
  `planetState`/`planetPort` so colony export shifts recolour static planets.
- Alternate `b987883` reviewed and rejected for render/boot/split defects: its
  still branch called full `draw(now)` once (freezing mid-flight ships/moons/pulses
  and ignoring colony/checkbox updates), coupled `orbit_view.js`'s IIFE to
  `mode`/`viewMode` globals, skipped the masked `scene.reset` on cold boot
  (running pre-history unmasked over 48 planets), and placed lite state in
  `gravity_gui.js`/`gui_maps.js` instead of `gui_lite.js`.
- `experiments/dom_stub.js`: `loadPage({ globals })` for injected constructors.

Decision: the boot's deferred pre-history now runs under the boot universe mask
(26 worlds) like every other reset; before, only the first boot world ran its
fast-forward unmasked and retired hidden ports afterwards. Lab worlds of a fresh
boot may differ from before in background trade detail; careers always reset
fully and are unchanged.

Measured (node stub): `?lite=1&mode=career` boot ~190 ms with seats from the
record vs ~2.8 s for a seed link; `?lite=1&mode=career&bot=easy` ~120 ms vs
~2.5 s; one fast-forward per boot (was up to three: ~20–60 ms each cold).
