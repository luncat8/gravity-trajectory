# 0.4.39 worklog — calibrate Voronoi distance

## Review

The previous implementation used the distance preset's 54/53/6 curves, but
applied experiment pixels directly to world units. This game's default field
has wider average spacing, so ordinary positions could land in the preset's
very low-frequency, quiet range. The experiment's link 1 is its overall default
(point-frequency mode); link 2 is the requested distance-frequency preset.
The prior implementation also changes pan to ship-relative bearing, mixes in
separate aiming/launch cues and uses a different output level and limiter, so it
is not a bit-identical copy of the experiment.

## Implementation

- Scale center distances by ×0.75 before the original distance curves and pan
  fade. The initial estimate compares area per point in a 1200×1000 experiment
  with 36 points to this game's 1600×1000 field with 26 planets; the square root
  of the area ratio is approximately 0.74. It does not depend on zoom.
- Add a persistent ×0.25–×2.00 distance scale, live during flight, only shown
  for Voronoi. Switching generators retains it; the existing generator and mute
  preferences remain respected. ×1 reproduces the experiment's raw curves.
- Checked the preset at world distances 50, 150 and 300: ×0.75 gives 37.5,
  112.5 and 225 experiment pixels, with frequencies about 524, 37 and 13 Hz.

## Validation

- `node experiments/voronoi_sound_test.js` checks independent preset formulas,
  actual voice parameters, live scale changes, switching, persistence and UI.
- `node experiments/trajectory_sound_test.js`, `node experiments/sound_test.js`
  and `node experiments/dom_smoke.js` pass.
- No real-browser listening test was performed; the calibration is an estimate.

## Next step

Audition close fly-bys and sparse career fields, adjusting the distance scale to
taste; revisit the preset or mixing if the desired character still differs.
