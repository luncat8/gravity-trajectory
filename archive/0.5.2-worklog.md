## A boundary that was wrong, and how it showed up

The stage-0 banners were placed by picking one anchor declaration per area. That is
cheap and it partitions the file exactly — but it does not check that each block
*means* one thing. `profit helpers` came out at 649 lines against the plan's
estimate of ~260, because everything between `helperHelperOrigin` and
`aimTraceStale` fell into it, including 185 lines of route-best code
(`resetBestSlot` … `clearRoutePlan`) that the plan assigns to `gui_route.js`.

So the rule now in the plan: **a block much larger than its file's estimate means
the anchor was chosen wrong — re-split it before cutting, never cut it as-is.** A
size that disagrees with the plan is the cheap signal that a boundary is semantic
nonsense, and it costs one `wc -l` to notice.

The same measurement went the other way for `gui_world.js`: `planet universe` and
`world attach & settings` are two plan rows but were physically adjacent, so
splitting them would have produced a file with an artificial seam and a divider
claiming a discontinuity that does not exist. They were merged into one banner and
one contiguous block. Adjacent blocks for one file → merge; interleaved blocks for
one file → keep the divider (`gui_route`, `gui_shop`, `gui_book`).

## Gate

`node --check` on both files, the global-scope gate, and `dom_smoke.js` per file —
its output stayed **byte-identical to the pre-split baseline** (the original
8,455-line monolith) at all six extractions, so the whole of stages 1–2 is provably
one behaviour-preserving chain rather than six separately-plausible steps.

Benches at the end of the stage: `game_bench`, `career_bench`, `bot_bench`,
`colony_bench`, `route_bench`, `gravity_bench` all pass. `game_bench`'s
deterministic quantities are unchanged against `experiments/logs/0.5.0-bench.txt`
(26/26 ends, 5404 steps, 1940 / 1991 / 223 replay frames, 1385 steps in 1 sliced
frame, 1944 px, purses 6.97 / 5.20 +2.20 / 11.01 +8.01 / 0.00); the ms columns are
lower (~30%) as they were in 0.5.1, i.e. environment, not this work.

`bot_bench` and `career_bench` passing matters beyond timing: they drive
`root.GravityScene`, so they are the check that twelve scripts still expose the
same contract the harness expects.

## One bug worth not repeating

The banner merge was written as "delete the banner and the blank above it", but the
loop that searched for the blank left the index pointing *at* the blank, so
`del L[j-1:j+1]` removed a closing brace and kept the banner. `node --check` failed
loudly and the file was restored from git in one command. When deleting a line
relative to another, name the anchor once and offset from it — do not reuse a
search cursor for two different things.

the first stage that changes declarations rather than moving blocks, because it
re-homes the shared `let` state to its owning file. Before cutting, list the 106
