# 0.3.5 worklog — scoreboard player switch and saved route best

## review

The 0.3.4 scoreboard made scores easy to compare, but YOU's user/bot control was
still remote in the right setup panel. Route planning also replaced the only
current entry on every aim edit, so a shorter experiment could discard a good
result. The aim stat duplicated variable-length prediction details and could
wrap onto another line.

## implementation

- Moved user/bot control into the upper-left YOU score row as a `bot` checkbox.
  The whole row is an implicit label, so clicking any part of it switches the
  player type; keyboard checkbox input and the existing restart/lock rules stay
  intact. Removed the old right-panel radio group.
- Added a manual route-best slot containing the start planet, exact snapped
  angle/speed units, and finished length. Only completed landing/map-exit traces
  replace it, and only when longer. `use best` restores those inputs through the
  ordinary sliced route tracer.
- Scoped the best to one start planet and run. Starting on another planet clears
  it immediately; restart, new seed, rule/player/field changes, replay startup,
  and return to lab clear it through the same reset paths. Clearing or cancelling
  the current aim leaves the valid best available for recovery.
- Kept the route-best button on its own full-width action row so its changing
  length cannot reflow the other actions. Made the aim value one line with an
  ellipsis and a full-value hover title.
- Documented the controls and added DOM coverage for weaker-adjustment retention,
  exact aim restoration, planet invalidation, restart invalidation, and checkbox
  switching in both directions.
