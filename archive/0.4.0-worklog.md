# 0.4.0 Worklog — User Helper Tools, Deselect, URL Params & MOSS Prompts

## Review of 0.3.7

Previous agent (0.3.7) fixed multi-user switching and `route` `use best` starvation
with immediate `routeStep` after `routeBegin`, reserved footer via
`visualViewport` + `ResizeObserver`, and unified `user`/`bot` rows. Benches
were green, but no user-facing helpers existed: players had to drag blindly to
compete with bot's 144-candidate search, empty clicks did not clear selection,
and fast visual tests required manual clicking.

## Implementation

### 1. Deselect on empty click — `gravity_gui.js`

- `onPointerDown` now checks `planet <0 && body <0`. If `!aiming && !pressing`
  and `selected >=0`, it calls `setSelected(-1)` + `helperUpdateUi()` then
  returns. No aim is started. This matches expected UX: click planet to
  select/tune `g`, click void to deselect.

### 2. Helper tools — `index.html`, `style.css`, `gravity_gui.js`

**UI**: New `div#helperGroup` inside `#cargoBody`, after horizon slider:
  - Caption `auto helpers` + dynamic `#helperTag` (`ready` / `best N px` / `scanning n/total %`).
  - Three `miniBtn` buttons:
    - `quick scan` — broad random scan. If a planet is selected, bias 42 % of
      draws to that planet plus 58 % random planets; otherwise uniform random
      over all free planets. Route: 28 candidates; flown: 20.
    - `scan P#` — focused scan on the selected planet (or armed `aimBody`).
      Disabled if free planet not selected or occupied (route). Label updates
      to `scan P3` dynamically.
    - `tweak best` — small perturbations around best plan (or armed aim if no
      best). Creates 16 candidates: base + 15 with `Δangle ∈ ±0.13 rad` and
      `Δspeed ∈ ±8 %`. Enabled only when `activeRouteBest().ready`.
  - Progress bar (`div.helperBar > div`) + `#helperProgressText` (`done/total · best N px`) + `stop` button.
  - Buttons disabled while scanning, while `replay.on`, `playerIsBot()`, or
    `gameLocked()` (broke/complete). Clear button doubles as `stop` when
    helper active.

**Logic**: New `helperProbe = new GravitySim` sharing world via
  `helperAttachWorld()`. `attachWorld()` now also wires `helperProbe`.
  Candidate generation uses fresh `Math.random()` each press — “next press will
  not calculate same attempts again.”

  Execution is sliced per frame to keep `≥60 fps`:
  - `helperRun(cands, mode)` stores queue, sets `helperState.active`,
    syncs `helperProbe.fieldT/fieldRate/horizon`, calls `helperBeginCandidate()`.
  - `helperBeginCandidate()` copies `activeSim().visited` into probe, sets
    `visitedCount`, refreshes field, calls `probe.routeBegin(origin, angle, speed, horizon)`.
  - `helperTick(budgetMs)` runs inside `frame()` (after `stepGame`, budget 3 ms):
    while budget remains → if `probe.routeActive` step slice (≤2 ms) else score
    candidate, update `helperState.best`, advance index, begin next.
    Scoring: route → `predLength` if `END_IMPACT|END_EXIT` else `-1e12`;
    flown → `estimateProfit`-aware score mimicking `bot.scoreProbe`.
  - On completion: picks `best`, sets `aimBody/aimAngle/aimSpeed`, `armed=true`,
    `placeGripFromSpeed()`, `dirty=true`. Gravity's normal `startAimTrace` then
    traces the chosen aim to confirm length and populate `slotBest` via
    `rememberRouteBest`. Helper never writes `slotBest` directly.

  Visibility: `helperUpdateUi()` called from `setSelected`, `refreshRouteBestUi`,
  `refreshGameUi`, and `helperTick`. It toggles disabled, updates labels, fills
  progress bar, and shows `helperTag`.

  Styles: `.helperActions` `flex-wrap`, `.helperBar` 6 px track with mint fill,
  responsive media rule for `×` layout on `≤820px`.

### 3. URL parameters — `gravity_gui.js`, `experiments/dom_stub.js`

- New `loadSearchParams()` parses `location.search` via `URLSearchParams`.
  Recognized keys: `mode` (`lab`/`game`), `game` (`1`), `seed`, `rate`/`speed`,
  `rule` (`tour`/`route`/`money`), `bot` (`off`/`easy`/`normal`/`hard`),
  `player`/`you`, `src`/`source` (`planets`/`ports`), plus `shots`/`end`/`len`
  for replay injection.
- Start path: `stopGame`/`startGame` + `setMode` + replay if `shots` present.
  Validation mirrors `GravityGame.decodeLink`: integer seed, rate range,
  rule/bot/player membership.
- Startup order: `attachWorld(); if (!loadSearchParams() && !loadLink()) refreshGameUi();`
  — search wins over hash.
- `dom_stub.js` extended: `location` now has `search`, `setSearch()`, and
  `href` includes both.
