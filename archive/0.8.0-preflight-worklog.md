## changes

- Added `experiments/classic_physics_test.js` to the fast runner. Fixed SHA-256
  fingerprints captured against the unchanged base runtime cover seeds 1/7/42:
  first-48 geometry, traits, special identities, gravity and post-placement
  PRNG state; seed 1 also covers 240 explicit static and synthetic moving-field
  integration steps, field samples, collision queries and area queries.
  Explicit little-endian doubles exclude future capacity tails. This is a
  numerical regression tripwire, not a replacement for live/predict parity,
  career opening checks or cross-engine accuracy tests.
- Updated the experiment guide with the focused baseline check, the current
  saved-map roster, and guidance consistent with AGENTS.md: select checks by
  touched area instead of running the full fast tier after every edit.
- Revised `0.8.0-plan-periodic-fft.md` as a standalone target specification:
  - 64 periodic career worlds (4 × current 16), existing empty-world law;
  - force/convolution signs, half-world tie convention, Fourier DC vs spatial
    origin, normalization, signed CIC mass and mean-zero potential;
  - four transforms per solve, rectangular geometry-keyed kernels;
  - lazy immutable field snapshots shared explicitly by matching sims,
    invalidation of all field writers, no solves on unchanged refresh/spawn;
  - no stale-grid async fallback, no eager per-sim grid allocation;
  - exact full-width planet-mask cache keys, topology/revision cache identity,
    byte-bounded opening-cache retention (4096 × 192² × 9 bytes ≈ 1.27 GiB);
  - capacity/count/extent distinction, periodic broad-phase bypass, explicit
    lattice order, seam-aware input/paint and moving-source CPU rendering;
  - topology in query/hash, saved starts, full saves, compact career playback,
    lite opening selection and fleet/probe setup;
  - independent vector-error oracle with cancellation and half-world-cut
    handling, solve counters, shared-snapshot isolation and fixed classic
    fingerprints instead of a moving HEAD comparison.
- Aligned the draft's status annotation and the downstream max-distance plan's
  classic-default/capacity wording. The human draft text is unchanged.

No game runtime files changed. FFT itself, roster expansion and physics
integration remain for the next step.
