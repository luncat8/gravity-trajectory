# 0.3.4 worklog — rule-aware scoreboard and rival comparison

## review

Reviewed the previous `0.3.3` bot implementation and its follow-up suggestion.
The bots were already wired to all three game rules (`tour`, `route`, `money`),
and `bot_bench.js` already measured their difficulty ladder separately per rule.
The presentation was the missing piece: the player's long score was embedded in
the right-side controls, the rival summary did not show route length, and an
in-flight rival's current route distance was not included in its summary. The
previous worklog's economy-coupling suggestion remains useful, but this step
prioritizes the requested comparison panel and makes multi-rule bot scoring
visible.

## implementation

- Added a game-only scoreboard to the upper-left HUD stack, above the orbital
  trade background panel. The stack collapses naturally to just the trade panel
  in lab mode and has a compact narrow-screen layout.
- Moved score and rival standing out of the game controls. Each visible actor now
  gets the active rule's primary score and supporting tie-breakers:
  - `tour`: systems, then shots / flight time / purse.
  - `route`: systems and route distance, then shots / flight time / purse.
  - `money`: purse, then systems / shots / flight time.
- Colored the player mint, R1 violet and R2 rose; added a live `AHEAD` / `BEHIND`
  / `EVEN` indicator that becomes `WIN` / `LOSS` / `TIE` when a run ends.
- Extended `GravityBot.actorSummary()` to include the current route length while a
  rival is flying, so the route row stays live rather than jumping only at landing.
- Documented the scoreboard and all-rule bot coverage. Extended the DOM smoke
  suite for tour, route, money, hard's two rivals, solo and lab visibility; added a
  bot summary check and updated the route score assertion for the new compact row.
- Reviewed route-bot horizon/weight changes experimentally. They weakened the
  existing route difficulty ladder, so those strategy changes were discarded;
  shipped bot tuning remains the benchmark-validated configuration.
