root. They were cut by **subject**, not by date, into eight files under

| `drafts/bots-and-tools.md` | controller, benches, balance lab | draft.txt §balance, §balance_lab, §helpers |

**The wording is the human's.** A script compared every original line >12 chars
against the new files: 10 did not match verbatim and each was checked by hand —
four had to be *restored* (`photo popup`, `players count change`, and the two
headers `## Corruption` / `## impulse engine…` whose text is now under a
descriptive heading), the rest are headings or markdown emphasis. The one line
that is an instruction rather than a note (*"make plans 0.5.x and start to
implement"*) is recorded in `drafts/README.md` instead of being carried as text.

What changed besides the order, and why it is still "as is":

- each section gains `→` lines: where the note stands in the code today (plan
  name, file, README row) or what a plan must decide first. Written after reading
  the implementation, so an already-shipped note is not planned twice.
- two notes were **corrected while placing them**, not re-worded: the Capital's
  `−3` and the A.R.F. tourist bias are *shipped* (0.5.11), and the bribe's
  "twice the flyby fee" is met at rot 50 by `visit × rot × 1e-2 × 4`.
- `0.4-draft-career.md` and `archive/draft.txt` were removed **after** the
  split; `git show 56dc80c:<path>` restores either.

References updated: `AGENTS.md` (files section + the workflow example),
`README.md` (`## files`), and `photos/prompts.md` gained the seven "rules that
hold the set together" the career draft asked for (that part *was* open).
