## H: the entry point becomes a call with a contract

The human's note asked for something the merge had left as a compromise: *"i
imagine it as — Helper call player if found problem, if call ignored or problem
solved ico disappears"*, `>>entry point at the moment of the problem`. The merge
had answered with the flight panel's state tag and the rule that H never speaks
first, which is silence, not a call.

**§4.11 added to `concept-helper-dialog-merged.md`** — the entry point as three
states (quiet / called / dismissed) and four mechanical rules:

- **what counts as a problem** — a closed `launchReason` gate behind an armed
  shot from this planet, plus the one case that blocks every shot (condition
  `0`, `WORN_OUT_BLOCK`). Both inputs already exist (`launchReason` from §4.4,
  `armed`/`aimBody` in `gui_aim.js`); nothing is authored for the trigger.
- **never nags** — one call per `gate id + planet + numbers` per visit; a
  dismissal is remembered for the visit and cleared with the transcript; no call
  during a settle, a replay or an open card, and not twice in a second.
- **the icon disappears by itself** — the call renders the current gate, so it
  is not a record: `launchReason` returning `null` quiets it in the same tick.
- **cost** — one string compare on the HUD tick; the badge and the dismissal map
  live in `commsState`; "H changes no state" still holds.
